
# Lab 01 — cURL + HTTP Fundamentals (Echo Server)

## What this lab is
A tiny local HTTP server that echoes what it receives (method/path/headers/body).
You use `curl` to learn HTTP systematically instead of memorising long commands.

## Why it matters (cybersecurity education)
API testing, incident response, and web security all rely on understanding:
- methods (GET/POST/PUT/PATCH/DELETE)
- headers vs body vs cookies
- redirects and status codes
- how to capture raw evidence (`-i`, `-v`, trace)

## GRC alignment
- Control understanding: what an HTTP request actually contains.
- Evidence quality: reproducible request/response transcripts.
- Repeatability: deterministic, local environment.

## Outcomes
You can build curl requests piece-by-piece and confirm exactly what the server received.
