
# Lab 02 — Mini API (In-Memory CRUD)

## What this lab is
A local REST-ish API with predictable routes:
- `POST /api/posts` creates
- `GET /api/posts` lists
- `GET /api/posts/<id>` reads
- `PATCH /api/posts/<id>` updates
- `PUT /api/posts/<id>` replaces
- `DELETE /api/posts/<id>` deletes

Runs in CLI; output viewable in browser.

## Why it matters (cybersecurity education)
Real incidents often involve APIs. This lab builds comfort with:
- collections vs resources
- IDs (which later become security-relevant)
- status codes and Location headers

## GRC alignment
Establishes a “known-good behaviour” baseline for CRUD operations and evidence capture.

## Outcomes
You can demonstrate correct HTTP semantics and predictable API behaviour.
