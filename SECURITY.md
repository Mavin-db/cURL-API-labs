# Security Policy

## Scope

This repository contains local-only educational labs designed to run on `127.0.0.1`.

They are intentionally simple and may include insecure patterns for learning purposes.

## Reporting Issues

If you identify a vulnerability in the lab code itself (not the intentional lab scenarios), please open an issue.

## Responsible Use

These labs are designed for:

- Local execution
- Educational purposes
- Personal experimentation

Do not run these techniques against systems you do not own or have explicit permission to assess.
